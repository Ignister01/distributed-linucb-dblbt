# Shadowing-enabled ns-3 diagnostic

This compact result is a five-second measurement-path check using the
comments0720-v2 runtime, TMC, a 4+4 Wi-Fi/NR-U cell, seed 410, and
shadowing enabled. It is not an adaptive-policy comparison.

The files report:

- Wi-Fi throughput 8.1212 Mbit/s, mean delay 1.793 ms, packet loss 0.0117,
  access overlap 0.3093.
- NR-U throughput 7.537 Mbit/s, mean delay 38.087 ms, packet loss 0.0828,
  access overlap 0.7726.

The schema, runtime identity, configuration, and command provenance are in
audit.json; the reduced metrics are in metrics.csv.
