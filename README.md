# Distributed LinUCB-Based Adaptive DB-LBT

Reproducibility artifact for *Distributed LinUCB-Based Adaptive DB-LBT with
Local Observations for Wi-Fi/NR-U Coexistence* by Yikai Wang, Yinuo Liu, and Hao Xu.

The repository contains the event simulator, distributed LinUCB controller,
experiment matrices, pinned Python environment, ns-3/5G-LENA/NR-U integration
patches, trained model, seed-level results, publication figures, packet-level
databases, paper source, and an online experimental appendix.

- [Six-page manuscript](paper/fcn6/final/distributed-linucb-adaptive-dblbt.pdf)
- [Final restricted-profile evidence](experiments/comments0720/README.md)
- [Online experimental appendix](docs/experimental-appendix.md)

## Quick Start

The supported environment is WSL2 Ubuntu 24.04 or native Ubuntu 24.04 with
Python 3.12. From the repository root:

```bash
bash scripts/bootstrap_linux.sh
bash scripts/run_smoke.sh
```

The smoke gate installs the pinned Python package, runs the test suite, executes
three short simulations, regenerates the report, and audits the artifacts.

## Reproduce the Experiments

Run or resume the complete event-level experiment:

```bash
DBLBT_WORKERS=8 bash scripts/run_overnight.sh
```

Run the packet-level ns-3 validation:

```bash
DBLBT_NS3_WORKERS=8 bash scripts/run_ns3_validation.sh all
```

The legacy event matrix contains 792 pretraining jobs and 940 formal jobs. A complete
event run produced about 6.87 GiB of compressed round-level records and took
approximately 7 hours on the reference laptop. The larger event records are
regenerated by the command above. The focused restricted-profile confirmation
used by the manuscript is documented in [experiments/comments0720/README.md](experiments/comments0720/README.md)
and reuses the committed discovery summaries and frozen seeds.

## Final Restricted-Profile Confirmation

Across 32 untouched seeds and eight alternating 4,096-round phases, distributed
LinUCB improves phase-averaged utility over fixed TMC by +0.007338 (95%
paired-bootstrap CI [+0.007093,+0.007584]; 32/32 positive). The low-load
4+4 phase contributes +0.015735; the high-load 6+6 phase contributes
-0.001058. The mixed-active-set whole-run diagnostic is retained as
-0.000668, which is why the manuscript reports the phase-conditional
estimator as primary. Median and P95 adaptation times are 736 and 928 rounds,
below the 4,096-round dwell time.

## Packet-Level Shadowing Diagnostic

The repository also retains a separate five-second ns-3 measurement-path
diagnostic with TMC, 4+4 nodes, seed 410, and 3GPP shadowing enabled. It is
not an adaptive-policy comparison. The resulting metrics are Wi-Fi throughput
8.1212 Mbit/s, mean delay 1.793 ms, packet loss 0.0117, and access overlap
0.3093; NR-U throughput 7.537 Mbit/s, mean delay 38.087 ms, packet loss 0.0828,
and access overlap 0.7726. Raw audit metadata and the CSV are in
experiments/comments0720/results/ns3-shadowing-benchmark/.

The earlier broad-matrix outcomes remain in the appendix as historical
evidence; they are not used as the primary claim of the six-page manuscript.
