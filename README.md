# Distributed LinUCB-Based Adaptive DB-LBT

Reproducibility artifact for *Distributed LinUCB-Based Adaptive DB-LBT with
Local Observations for Wi-Fi/NR-U Coexistence* by Yikai Wang and Yinuo Liu.

The repository contains the event simulator, distributed LinUCB controller,
experiment matrices, pinned Python environment, ns-3/5G-LENA/NR-U integration
patches, trained model, seed-level results, publication figures, packet-level
databases, paper source, and an online experimental appendix.

- [Six-page manuscript](paper/fcn6/final/distributed-linucb-adaptive-dblbt.pdf)
- [Online experimental appendix](docs/experimental-appendix.md)

## Quick Start

The supported environment is WSL2 Ubuntu 24.04 or native Ubuntu 24.04 with
Python 3.12. From the repository root:

```bash
bash scripts/bootstrap_linux.sh
bash scripts/run_smoke.sh
```

The smoke gate installs the pinned Python package, runs the test suite, executes
three short simulations, regenerates the report, and audits the artifacts.

## Reproduce the Experiments

Run or resume the complete event-level experiment:

```bash
DBLBT_WORKERS=8 bash scripts/run_overnight.sh
```

Run the packet-level ns-3 validation:

```bash
DBLBT_NS3_WORKERS=8 bash scripts/run_ns3_validation.sh all
```

The event matrix contains 792 pretraining jobs and 940 formal jobs. A complete
event run produced about 6.87 GiB of compressed round-level records and took
approximately 7 hours on the reference laptop. The 27 retained ns-3 SQLite
databases are included because they are compact; the larger event records are
regenerated by the command above.

## Reported Outcomes

The registered outcomes are H1 `pass`, H2 `fail`, H3 `pass`, H4 `pass`, and H5
`inconclusive`. Negative and inconclusive evidence is retained as produced. The
aggregate adaptive-minus-fixed-TMC held-out utility difference is `+0.001556`,
but the effect is scenario dependent; the seed-level values are available in
`results/tables/per-seed.csv`.
